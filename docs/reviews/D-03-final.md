## Находки по бонусам

| Severity | Находка | Доказательство | Исправление |
|---|---|---|---|
| **High** | Платёж, созданный задним числом (например, еженедельный с датой два года назад), сразу ставил напоминание о просрочке на **каждый** прошлый период — лавина сообщений в Telegram/почту | падающий тест: 105 напоминаний | напоминаем только о просрочках не старше `OVERDUE_REMINDER_WINDOW_DAYS` (30) → тест зелёный |

Проверено и корректно: файлы чеков хранятся под серверным uuid-именем (нет path traversal), тип определяется по сигнатуре,
отдаются с `X-Content-Type-Options: nosniff` и только с сессией; кнопка Telegram подписана HMAC и принимается только из чата
`.env`; бюджет меняет только админ (403 для пользователя); журнал — только админ.
